# Card & Transactions Overview

This project is a React + TypeScript application displaying a card overview page where a user can:

- Select one of the available cards
- View transactions for the selected card
- Filter transactions by minimum amount
- Navigate through cards using a responsive carousel
- View a responsive UI across screen sizes

## Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS (v4)
- Zod (runtime validation)
- Vitest + React Testing Library (unit testing)

## Installation

This project uses Yarn.

```
yarn install
```

## Run the Project

```
Run the Project
```

## Run Tests

```
yarn test
```

To run once (CI mode):

```
yarn test:run
```
